What this page does not claim. No ground-truth record exists for these recordings, so nothing here is a precision or accuracy measurement — every count is what the system reported, not what was true. The system cannot re-identify a person across a tracking break, so one person may appear as several entries, and a person who leaves and returns is not verified to be the same person. Object detection runs against a hosted service, which conflicts with the offline requirement in Problem Statement 2. Reviewer decisions on this page are not saved. The buttons change only what this browser shows; nothing is written back. Persisted, append-only review is specified in docs/OUTPUT_CONTRACT.md and is not yet built. This page also still renders the older pipeline/verdict.py ladder rather than the frozen output contract.
